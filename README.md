# 📚 Book Store Project

This is a multi-page web project for a Book Store, featuring a clean user interface and functional forms.

## 🚀 Project Overview
This project consists of four main web pages:
- **Home (Index):** The landing page of the Book Store.
- **Registration:** A user sign-up form with real-time validation for mobile numbers and email IDs.
- **Feedback:** A dedicated page for users to provide their reviews.
- **Booklist:** A curated list showing available books in the store.

## 🛠️ Features
- **Responsive Design:** Styled using CSS gradients and modern layouts.
- **Interactive UI:** Smooth hover effects on buttons and titles.
- **Vanilla JS:** Pure JavaScript used for form logic without any external libraries.

## 📂 File Structure
- `index.html` - Main landing page.
- `registration.html` - Sign-up form with JavaScript validation.
- `feedback.html` - User feedback page.
- `book_list.html` - Displaying the collection of books.
- `book.jfif` - Image assets used in the project.

## 💻 How to Run
1. Download or clone this repository.
2. Open `index.html` in any web browser.
